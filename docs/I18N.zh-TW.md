# 文件國際化

## 支援語言

Post-Training RSI Pipeline 的 Public human-facing documentation 支援：

- English（`en`），作為 Canonical technical language；
- 繁體中文（`zh-TW`），作為持續維護的 Peer translation。

Root README 與 Community health documents 必須具有雙向 Language link，且應在同一個 Pull Request 更新。

## 檔名規則

| English | 繁體中文 |
|---|---|
| `README.md` | `README.zh-TW.md` |
| `CONTRIBUTING.md` | `CONTRIBUTING.zh-TW.md` |
| `docs/README.md` | `docs/README.zh-TW.md` |
| `path/name.md` | `path/name.zh-TW.md` |

Machine contract、Code、JSON、YAML、Schema ID、CLI name、State Machine state、Digest field 或 Stable artifact identifier 不使用 Locale suffix。

## 翻譯契約

翻譯必須保留：

- Claim strength 與 Evidence level；
- Warning、Limitation、Non-goal 與 Failure behavior；
- Command、Path、Identifier、Version constraint 與 Link；
- Security、Privacy、Licensing 與 Data-handling requirement；
- Table、Diagram、Acceptance criteria 與 Responsibility boundary。

若翻譯 Technical identifier 會破壞 Copy/paste 或改變語意，必須保留原文。解釋性文字可在第一次出現時保留英文專有名詞。

## 受控制的例外

以下 Markdown 類型不自動改寫或複製，因為語言變更可能改變 Execution、Provenance 或 Evidence：

- `AGENTS.md`、`CLAUDE.md`、`SKILL.md` 與其他 Executable Agent instruction contract；
- Generated card、Model output、Receipt、Fixture、Snapshot、Replay artifact 與 Signed evidence；
- Vendored third-party notice 或 Upstream documentation；
- Byte identity 屬於 Evidence 的 Archived historical record。

這些檔案必須可由 Bilingual index 到達。可翻譯 Human-facing summary，但 Canonical artifact 保持不變，且必須標示其狀態。

## Review 與 CI

`docs/i18n-manifest.json` 列出持續維護的 Document pairs。`scripts/check_docs_i18n.py` 驗證每一組檔案存在、具有相同 I18n key，並包含雙向 Navigation。CI 只檢查結構，不會判斷翻譯語意品質；Parity 仍由 Reviewer 負責。

新增 Public document 時必須符合其中一項：

1. 同時新增兩種語言並登錄 Pair；
2. 採 Intentional bilingual inline 並登錄；
3. 以理由列為 Controlled exception。

不接受未標示的 English-only public documentation。
