# Support

Post-Training RSI Pipeline is maintained as open-source research and engineering software. Community support is best-effort and does not include a service-level agreement.

## Use the right channel

| Need | Channel |
|---|---|
| Reproducible bug | GitHub Issue with version, environment, minimal reproduction, logs with secrets removed, expected result, and actual result |
| Feature or design proposal | GitHub Issue with user outcome, constraints, alternatives, evidence plan, and non-goals |
| Documentation correction | Pull Request or documentation Issue |
| Security vulnerability | Private route in [SECURITY.md](SECURITY.md) |
| Conduct concern | Private maintainer route in [CODE_OF_CONDUCT.md](CODE_OF_CONDUCT.md) |
| Commercial deployment or private integration | Outside the public support commitment; do not post proprietary data |

## What maintainers may ask for

A report may be closed or paused when it lacks a supported version, reproduction, evidence, a clear request, or a safe public data set. Maintainers may request a smaller case, deterministic fixture, exact command, trace, or environment inventory.

## Boundaries

Public support does not guarantee:

- production readiness, uptime, migration, or backward compatibility;
- model quality, profitability, safety certification, legal compliance, or external runtime availability;
- review or merge of a proposed change;
- debugging of private systems without an approved private engagement and data-handling agreement.

Search existing documentation, Issues, and Pull Requests before opening a new report. Never post secrets or private data.
