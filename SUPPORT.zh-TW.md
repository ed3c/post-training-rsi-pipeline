# 支援

Post-Training RSI Pipeline 以 Open-source research 與 Engineering software 維護。Community support 採 Best-effort，不提供 Service-level agreement。

## 使用正確管道

| 需求 | 管道 |
|---|---|
| 可重現 Bug | GitHub Issue，包含 Version、Environment、Minimal reproduction、已移除秘密的 Log、Expected result 與 Actual result |
| Feature 或 Design proposal | GitHub Issue，包含 User outcome、Constraints、Alternatives、Evidence plan 與 Non-goals |
| 文件修正 | Pull Request 或 Documentation Issue |
| Security vulnerability | [SECURITY.zh-TW.md](SECURITY.zh-TW.md) 的 Private route |
| Conduct concern | [CODE_OF_CONDUCT.zh-TW.md](CODE_OF_CONDUCT.zh-TW.md) 的 Private maintainer route |
| Commercial deployment 或 Private integration | 不屬於 Public support commitment；不得張貼 Proprietary data |

## Maintainer 可能要求的資訊

若報告缺少 Supported version、Reproduction、Evidence、清楚 Request 或安全的 Public data set，可能被關閉或暫停。Maintainer 可要求更小的 Case、Deterministic fixture、Exact command、Trace 或 Environment inventory。

## 邊界

Public support 不保證：

- Production readiness、Uptime、Migration 或 Backward compatibility；
- Model quality、Profitability、Safety certification、Legal compliance 或 External runtime availability；
- 提案一定會被 Review 或 Merge；
- 未經核准的 Private engagement 與 Data-handling agreement，即協助除錯 Private system。

建立新報告前請先搜尋既有文件、Issues 與 Pull Requests。不得張貼 Secret 或 Private data。
